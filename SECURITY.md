# Security Policy

## Scope

This policy covers security vulnerabilities in the public software projects maintained under this GitHub profile.

## Reporting

Do not disclose exploitable vulnerabilities, credentials, tokens, private keys, or sensitive target information in public issues.

For vulnerabilities that could affect users, contact the maintainer privately through the contact method published in the affected project's repository or profile. Include the affected project, version or commit, impact, reproduction steps, and relevant mitigations.

## Responsible disclosure

Allow reasonable time for investigation, remediation, and release coordination before public disclosure.

## Safety

Security testing must be limited to systems and targets for which you have explicit authorization.
