# Contributing

Thanks for contributing to the projects in this profile.

## Before opening an issue

- Search existing issues first.
- Include the project name and version or commit when relevant.
- Provide reproducible steps for bugs.
- Never include secrets, credentials, private keys, or sensitive target data.

## Pull requests

1. Keep changes focused on one problem.
2. Explain the motivation and implementation.
3. Add or update tests when behavior changes.
4. Update documentation when public behavior changes.
5. Keep security-sensitive details out of public issues; use the project's security policy instead.

## Security research

Only test systems and targets you are authorized to assess.
