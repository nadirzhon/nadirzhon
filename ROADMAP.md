# Engineering Roadmap

This roadmap tracks the direction of the public engineering portfolio.

## Security tooling

- Improve MCP security analysis and reporting
- Expand automated security checks
- Add reproducible test fixtures

## AI automation

- Improve agent orchestration and guardrails
- Add evaluation datasets and regression tests
- Document model and tool boundaries

## Backend engineering

- Strengthen API reliability and observability
- Expand integration tests
- Improve performance profiling

## Infrastructure

- Harden containerized deployments
- Improve CI quality gates
- Add operational documentation

## Principles

Prioritize reproducibility, explicit security boundaries, maintainability, and useful documentation over activity for activity's sake.
