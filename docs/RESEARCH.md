# MCP Security Research

## State of MCP Security

The profile includes a dedicated research project examining security hardening issues in MCP servers.

## Reproducibility checklist

- Record the exact scanner version or commit.
- Record the server versions and configurations tested.
- Document inclusion and exclusion criteria.
- Keep raw observations separate from interpreted findings.
- Publish methodology and limitations alongside aggregate results.

## Interpretation

Research percentages and severity conclusions should always be read together with the published methodology, sample, and limitations.
